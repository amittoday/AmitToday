# Amit Online Services (AOS) - Portal & Facilitation Management System

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.8-blue?logo=typescript)](https://www.typescriptlang.org/)

An enterprise-grade government documentation and digital facilitation portal built with React, Vite, Express, and Google Gemini AI.

## Key Features

- **Document Facilitation & Order Management**: Full kanban pipeline for government applications with operational status tooltips and negative countdown SLA timers.
- **Notary Verification Portal**: Printable A4 legal summaries, verified completion certificates with embedded compliance metadata, and bulk deletion management.
- **Smart OCR Processing**: Multi-threaded Tesseract OCR pool, live OCR sensitivity threshold controls, and staff text correction editor with Google Sheets syncing.
- **Category Analytics**: Recharts Treemap and distribution visualizers for document classifications.
- **Smart System Archiver**: Automated periodic log archiver with configurable frequency.

## Build & Run

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
