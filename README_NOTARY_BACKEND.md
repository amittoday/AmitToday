To deploy the backend for the Central Notary Public Application:
1. Open your Google Apps Script editor.
2. Create a new file or replace your existing code with the contents of `gas_notary_backend.js`.
3. Update `YOUR_ROOT_FOLDER_ID`, `YOUR_SPREADSHEET_ID`, and `YOUR_WHATSAPP_API_KEY` placeholders.
4. Deploy as a Web App to enable remote API fetching.
